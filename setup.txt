Django API
****************************
1. Create project folder & clone/download DjangoAPI
2. cd into API
3. python3.11 -m venv venv
4. source venv/bin/activate (should now see venv)
5. pip install --upgrade pip setuptools wheel
6. pip install -r requirements.txt
7. python manage.py runserver

NOTE: may require the following
pip install django
pip install djangorestframework
pip install django-cors-headers
pip install django-filter
pip install drf-spectacular

React Frontend
****************************
1. Create React app, cd into project folder
2. npm create vite@latest shop-frontend -- --template react
3. cd shop-frontend
4. npm install
5. npm run dev

NOTE: may require the following
# Install Axios for making HTTP requests to the Django API
npm install axios

# Install React Router for handling page routing
npm install react-router-dom
